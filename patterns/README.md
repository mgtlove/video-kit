# Patterns index

`index.json`: for each of the 35 moves, its id, title, group (word-and-picture, voice-and-sound, argument, camera), the phrases a person would use to ask for it, one line of effect, what a rig needs for it, and the path of the full note in `video-reference/styles/patterns/`. Made by `vkit sync-reference` from the notes; edit the notes, not this file. The menu's item 7 reads it; `?` opens the full note when the reference is cloned beside the kit.
